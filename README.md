# CHORUJARO COFFEE ROAST MANAGER v1.1.0

CHORUJARO COFFEE専用の焙煎記録PWAです。

## できること
- 豆マスター登録（産地・精製方法・品種・メモ）
- 豆ごとのマスター焙煎カーブ登録・編集
- ストップウォッチ（開始・一時停止・再開・リセット）
- 温度と経過時間のセット記録
- 1ハゼ・2ハゼ・煎り止めイベント記録
- マスターと今回の焙煎カーブの重ね合わせ表示
- 焙煎記録の保存・閲覧・削除
- 過去の焙煎記録を豆のマスターカーブに登録
- JSONバックアップ・復元
- PWA / Service Workerによるオフライン対応

## 起動方法
PWAとして利用するにはHTTPSで配信してください。ZIPを展開し、GitHub Pagesなどの静的ホスティングに全ファイルを配置します。
ローカルPCで確認する場合は、フォルダ内で簡易HTTPサーバーを起動します（例：`python -m http.server 8000`）。その後 `http://localhost:8000` を開きます。
`file://` で直接開いた場合、Service Workerによるオフライン機能は動作しません。

## Androidへのインストール
1. HTTPSで公開したURLをAndroidのChromeで開く
2. Chromeのメニューから「アプリをインストール」または「ホーム画面に追加」
3. 初回はオンライン状態でアプリを開き、必要ファイルをキャッシュさせる
4. 以降、オフラインでも主要機能を利用可能

## データについて
- 豆マスターと焙煎記録はブラウザ内のlocalStorageに保存します。
- 焙煎中の温度点・イベント・タイマー状態も随時保存し、ページ再読み込み後に作業を復元します。
- 焙煎データを外部サーバーへ送信する処理はありません。
- ブラウザのサイトデータ削除・端末故障・ストレージ破損に備え、設定画面からJSONバックアップを定期的に保存してください。
- JSON復元は現在のデータを置き換えます。復元前に必ず現状をバックアップしてください。

## 注意点・次期改善候補
- 本版の温度記録は手入力です。外部温度センサー連携は未実装です。
- グラフは記録点を直線で結びます。RoR（昇温率）表示、マスターとの差分表示は次期候補です。
- 現在の保存方式は単一端末・単一ブラウザ向けです。長期運用前にIndexedDB化やデータ整合性テストを追加することを推奨します。
- 初回公開前に実機Androidで、画面ロック・アプリ切替・長時間焙煎・バックアップ復元をテストしてください。
